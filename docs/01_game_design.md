# 01 ゲームデザイン仕様

## コンセプト

**Running Monster** は、実際のランニング行動をモンスター育成ゲームと融合させたフィットネス×RPGアプリです。走ることでモンスターが育ち、モンスターが育つことで走るモチベーションが上がるという、正のフィードバックループを核に設計されています。

**ジャンル:** フィットネス × モンスター育成 RPG  
**ターゲット:** 運動習慣をつけたい 20〜35 代のカジュアルランナー  
**参考:** Duolingo（習慣化）、Finch（育成愛着）、Pokémon Sleep（毎日開く動機）  
**UI 方針:** Duolingo / Finch / Pokémon Sleep — ライトテーマ・明るい・丸い・余白多め

---

## コアループ

```
走る → EXP・コイン獲得 → モンスター成長 → 進化選択
 ↑                                              ↓
 └──── ミッション・実績・ガチャ ────────────────┘
```

1. **走る** — GPS 計測で距離を記録（最低 0.5km・3分）
2. **報酬獲得** — EXP・コインを算出（距離・時間帯ボーナス適用）
3. **モンスター成長** — EXP でレベルアップ、進化分岐の解放
4. **コンテンツ消費** — ガチャ引き（コイン消費）、ミッション達成、実績解放
5. **リテンション** — 連続日数ストリーク、週間目標、デイリーミッション

## 報酬システム

### 基本報酬（1km あたり）

| 報酬種別 | 基本値 | 乗数上限 |
|---------|-------|--------|
| EXP | 100 | **1.8×**（全ボーナス合算上限） |
| コイン | 100 | 1.0×（乗数なし） |

### EXP ボーナス乗数（**掛け算方式**・上限 1.8×）

| 条件 | 乗数 |
|-----|-----|
| 距離 5km 以上 | 1.2× |
| 距離 10km 以上 | 1.5× |
| 朝ラン（**5:00〜7:59**） | 1.1× |
| 夜ラン（20:00〜23:59） | 1.1× |

**計算方式:** 全ボーナスを乗算し、合算後に上限 1.8× でキャップ。

```
totalMultiplier = distanceMultiplier × timeMultiplier × (将来ボーナス...)
finalExp = (baseExp × min(totalMultiplier, 1.8)).round()
```

**例:**
- 10km 朝ラン: 1.5 × 1.1 = **1.65×**
- 5km 夜ラン: 1.2 × 1.1 = **1.32×**
- 10km 通常: **1.5×**

> 上限 1.8× は将来のボーナス追加（イベント乗数等）を見据えたキャップ。現行の最大は 1.65×。

### 無効ラン

| 条件 | 結果 |
|-----|-----|
| 距離 < 0.5km | 報酬 0・記録なし |
| 時間 < 3分（180秒） | 報酬 0・記録なし |
| 速度 > 25km/h の区間 | その区間を除外 |

## レベルシステム

### 累積 EXP テーブル

| レベル | 必要累積 EXP | 目安走行距離 |
|-------|------------|------------|
| 1 | 0 | 0 km |
| 10 | 1,000 | 10 km |
| 20 | 5,000 | 50 km |
| 30 | 10,000 | 100 km |
| 40 | 20,000 | 200 km |
| 50 | 40,000 | 400 km |

- レベル上限: **50**（ソフトキャップ）
- Lv50 以降も EXP は蓄積するが数値変化なし
- 各ミルストーン間は線形補間

### レベルアップ体験
- ゲーム内でレベルアップが発生した場合、アニメーション演出（弾性バウンス）を表示
- 実績チェックを自動実行
- 進化解放条件を即時評価

## 週間システム

| 要素 | 仕様 |
|-----|-----|
| 週間目標 | 30km/週 |
| リセット | 毎週月曜日 0:00 |
| 目標達成表示 | 「目標達成！」ラベル＋グリーン強調 |
| 進捗 | ホーム画面の週間カードにプログレスバー表示 |

---

## ストリークシステム

- **定義:** ランを記録した日が連続している日数
- **条件:** 1日に最低 1 ランを記録
- **リセット:** 1日でも記録なし → ストリーク 0 にリセット
- **表示:** ホーム画面の炎アイコン＋「n日連続」
- **実績:** 3日・7日・30日連続で報酬

---

## バランス指針

1. **ペイウォールなし** — 課金で進化・レベルを買えない
2. **走力に比例** — 実際に走った距離がそのまま進歩に反映される
3. **casual friendly** — 週 5km でも 18 ヶ月でエンドゲームに到達できる
4. **cosmetics only** — 課金要素はすべて見た目のみ
