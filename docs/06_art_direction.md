# 06 アートディレクション

## ビジュアルフィロソフィー

**キーワード:** Friendly / Playful / Motivating  
**参考スタイル:** Duolingo、Finch、ポケモン GO（UIスタイルのみ）  
**アンチパターン:** 重厚なファンタジー、ダーク・エッジィ、リアル系

ユーザーが毎日気持ちよく開けるアプリを目指す。走ることをポジティブに捉えられる明るい配色とキャラクター表現。

```

バイオレット（主要アクション）→ 活力・達成感

サンフラワーゴールド        → 報酬・価値・特別感
グリーン                  → 成長・達成・自然
```

パステル寄りの明るいトーンで統一。黒は使わず、ネイビー（`#1A1333`）で代替。

### 目指すキャラクターデザイン方向性

- **Lv1（Runmon）:** シンプルで丸っこい。走る球体スライムのような親しみやすい外見
- **Lv10（第1進化）:** 四肢が生え、獣らしさが増す
- **Lv20（第2進化）:** 体格が整い、特徴的な角や翼など属性が出る
- **Lv30/40（最終形態）:** 迫力と美しさを兼ね備えた、ランドマーク級の存在感
- **共通トーン:** 可愛さと格好良さを両立。ポップイラスト調（アニメ寄り）

## アセット仕様（実装予定）

### ファイル構造

```
assets/monsters/
├── {evolutionId}/
│   ├── {color}/
│   │   └── idle.png          ← 通常表示
│   │   └── skins/
│   │       └── {skinId}/
│   │           └── idle.png  ← スキン適用時
```

### フォールバック優先順位

1. スキンバリアント（Lv50 & スキン装備時）
2. カラー固有バージョン
3. 進化形態共通バージョン（色なし）

### 推奨画像サイズ

| 用途 | 推奨サイズ |
|-----|---------|
| ホームヒーロー | 360×360px（画面幅 72%） |
| モンスターカード | 160×160px |
| ランサブ表示 | 80×80px |
| プロフィールカード | 120×120px |

画像形式: PNG（透過背景）  
@2x/@3x: Flutter の devicePixelRatio に合わせて提供

## UI ビジュアルボキャブラリー

### 形状言語

- **カード:** border-radius 20px（大きめの角丸で柔らかく）
- **ボタン:** 完全な Pill 形状（border-radius 100）
- **チップ・バッジ:** 小さめの rounded（8px）
- **全体:** 直角・シャープなコーナーを使わない

### 影（Shadow）

- Elevation による影は使わず、**カスタムボックスシャドウ**を使用
- 色: メインカラーのアルファ値下げ（黒影は使用しない）
- 例: `BoxShadow(color: Color(0x1A7C4DFF), blurRadius: 16)`

### グラデーション

- 背景グラデーション: ラベンダーホワイト → ライトラベンダー（縦方向）
- モンスターヒーロー背景: ブランドカラーを薄めたソフトグラデーション
- ガチャ・特殊シーン: ダーク系グラデーション（星フィールド演出）

### 発光（グロウ）エフェクト

- 走るボタン: `#9C6FFF` のシャドウで疑似グロウ
- 進化バナー: シマーアニメーション（グラデーション横スライド）
- ガチャ SSR 演出: 強いゴールドグロウ

## アニメーションビジュアル方針

| 演出 | 感触 | 技術 |
|-----|-----|-----|
| モンスター呼吸 | 生きている感・愛着 | Scale loop（3秒） |
| レベルアップ | 達成の高揚感 | Elastic bounce |
| シマー | 期待感（進化バナー） | Shimmer sweep |
| カウンター | 報酬を「感じさせる」 | Int animation（easeOut） |
| ガチャマシン | ドキドキ感 | Custom 1.2秒アニメ |

## 進化ビジュアル演出

**進化選択画面の意図:**
- 2 つの選択肢を対等に並べ、どちらを選ぶかのワクワク感を演出
- 各選択肢にプレビュー（絵文字・名前・フレーバーテキスト）
- 「決定後は変えられない」緊張感を UI で表現（赤みを帯びた警告テキスト等）
