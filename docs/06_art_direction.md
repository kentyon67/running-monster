# 06 アートディレクション

## ビジュアルフィロソフィー

**キーワード:** Friendly / Playful / Motivating / Warm  
**参考スタイル:** Duolingo・Finch・Pokémon Sleep  
**アンチパターン:** ネオン、サイバーパンク、ダーク SF、過度なグロー、重厚ファンタジー

ユーザーが毎朝気持ちよく開けるアプリを目指す。モンスターが主役であり、UI はモンスターを引き立てるための舞台装置に徹する。

---

## カラーパレット概要

```
ラベンダー系（背景）       → 柔らかさ・癒し・非日常感
バイオレット（主要アクション）→ 活力・達成感・ブランドカラー
コーラルオレンジ（アクセント）→ 元気・モチベーション・暖かみ
サンフラワーゴールド        → 報酬・価値・特別感
グリーン                  → 成長・達成・自然
```

パステル寄りの明るいトーンで統一。黒は使わず、ネイビー（`#1A1333`）で代替。

## モンスターデザイン方針

### 最終目標スタイル

**3D 風 2D イラスト / Soft Clay Render 風**

- ぷっくりとした立体感のある 2D イラスト
- 柔らかいハイライト・シャドウで「粘土細工」的な質感
- 完全な 3D ではなく、2D で描かれた 3D 感（手描きテイスト保持）
- 背景透過 PNG での納品・`Image.asset()` で運用

**スタイル進化軸:**
- 初期形態（ランモン）: 丸くてプニプニ、子犬・スライム的な親しみやすさ
- 中間形態: 体格が整い、特徴ある外見へ
- 最終形態: 格好よさ・迫力・美しさを備えた「完成形」

### CustomPainter の位置づけ

| フェーズ | 用途 |
|--------|-----|
| β版・開発中 | CustomPainter で代替表示（フォールバック） |
| 本番リリース | `Image.asset()` で実画像を表示 |
| 実画像未収録時 | CustomPainter をフォールバックとして維持 |

CustomPainter は**本番の主要表示には使用しない**。画像アセット方式への移行を前提として設計すること。

### カラーバリエーション

| カラー | テーマ | モンスターの印象 |
|-------|-------|-------------|
| 赤（`#E53935`） | 情熱・炎・スピード | 活発・力強い・熱血 |
| 青（`#1565C0`） | 冷静・空・知性 | スマート・クール |
| 緑（`#2E7D32`） | 自然・大地・成長 | 穏やか・芯が強い |

カラーは**純粋に見た目の違いのみ**。ステータスへの影響なし。同じランモンの色違い。

## ガチャ演出デザイン

### ガチャマシンデザイン

**コンセプト:** ランニングシューズ型ガチャマシン

```
[ランニングシューズの形をした専用ガチャマシン]
  ↓ 靴ひもを引くアクション
  ↓ ソールが発光（レアリティカラーで光る）
  ↓ シューズのつま先からカプセルが排出
  ↓ カプセルが開いてアイテム出現
```

### 演出フロー

1. **靴ひもを引く:** ユーザーがボタンタップ → シューズのひもが引かれるアニメーション
2. **ソール発光:** シューズのソール部分がレアリティカラーで発光（N=白, R=青, SR=紫, SSR=金）
3. **カプセル排出:** シューズ前方からカプセルがポップ
4. **オープン演出:** カプセルが開き、アイテムがフロートイン
5. **結果表示:** アイテム名・レアリティ・説明テキスト

### レアリティ別演出強度

| レアリティ | 発光色 | 演出時間 | 追加演出 |
|---------|-------|--------|--------|
| N | ホワイト | 0.8秒 | なし |
| R | スカイブルー | 1.2秒 | 軽いパーティクル |
| SR | マゼンタ | 1.8秒 | パーティクル + 光の柱 |
| SSR | ゴールド | 2.5秒 | 全画面フラッシュ + 紙吹雪 |

### フォールバック優先順位

1. スキンバリアント（Lv50 & スキン装備時）

| 用途 | 推奨サイズ | 備考 |
|-----|---------|-----|
| ホームヒーロー | 360×360px | @2x/@3x 提供推奨 |
| モンスターカード | 160×160px | — |
| ランサブ表示 | 80×80px | — |
| プロフィールカード | 120×120px | — |

**形式:** PNG（背景透過必須）  
**スケーリング:** Flutter の `devicePixelRatio` に合わせて 1x/2x/3x 提供

## UI ビジュアルボキャブラリー

### 形状言語

- **カード:** border-radius 20px（大きめの角丸で柔らかく）
- **ボタン:** Pill 形状（border-radius 100）
- **チップ・バッジ:** 小さめの rounded（8px）
- **全体:** 直角・シャープなコーナーを使わない

### 影（Shadow）

- 黒い影は使用しない
- カラーシャドウのみ: メインカラーをアルファ値下げ
- 例: `BoxShadow(color: Color(0x1A7C4DFF), blurRadius: 16)`

### グラデーション

- 背景: ラベンダーホワイト → ライトラベンダー（縦方向・穏やか）
- モンスターヒーロー背景: モンスターカラーを薄めたソフトグラデーション
- ラン準備画面: 明るい昼/夜の情景を意識した背景（星フィールドは廃止検討）

### グロー・光彩エフェクト

- 走るボタン: 控えめなカラーシャドウ（派手なグロー禁止）
- 進化バナー: シマーアニメーション（光のラインが横に流れる程度）
- ガチャ SSR: 画面フラッシュ（白→ゴールド、1.5秒、その後落ち着く）
- **禁止:** ネオン管のような発光、SFっぽいグリッドライン、サイバーな演出

## アニメーションビジュアル方針

| 演出 | 感触 | 技術 |
|-----|-----|-----|
| モンスター呼吸 | 生きている感・愛着 | Scale loop 3秒（`easeInOut`） |
| レベルアップ | 達成の高揚感 | Elastic bounce（`elasticOut`） |
| 進化バナーシマー | 期待感の醸成 | Shimmer sweep |
| 報酬カウンター | 「もらった」実感 | Int animation（`easeOut`, 600ms） |
| ガチャマシン | ドキドキ・ワクワク | シューズ専用アニメ |
| 最終進化演出 | 感動・達成感 | フルスクリーン演出（将来実装） |

## NG 事例（禁止事項）

| NG | 理由 |
|----|-----|
| ネオン文字・光るアウトライン | SF・サイバー感になる |
| グリッドパターン | ダーク SF 感 |
| 黒背景メイン画面 | 重い・怖い・フィットネス向きでない |
| 別種族化（赤=狐、青=イルカ等） | ランモンは 1 種族・カラー違いのみ |
| 強い白飛び・派手なレインボーエフェクト | 安っぽく見える |
