# 07 マネタイズ仕様

## 収益モデル

**ジャンル:** Free-to-Play（F2P）+ 広告  
**基本方針:** ゲームプレイの公平性を損なわない「倫理的 F2P」

---

## 収益ソース

| # | 収益源 | モデル | 現状 |
|---|-------|-------|-----|
| 1 | ガチャ（コイン消費） | 間接課金（要 IAP 実装） | コインは走行で無料取得可 |
| 2 | 報酬広告 | 広告視聴報酬 | 実装済み |
| 3 | コイン IAP | 直接購入 | 未実装（将来拡張） |

---

## 1. ガチャ（主収益源）

### 概要

ランニングで獲得したコインを消費してガチャを引く。コインは課金でも購入できることを想定（IAP 未実装段階では走行のみ）。

### コスト設計

| モード | コイン消費 | 単価（予定 IAP 価格例） |
|-------|---------|-------------------| 
| 1連 | 500 コイン | 〜¥200 相当 |
| 10連 | 4,500 コイン | 〜¥1,800 相当（1連×10 より 500 コイン お得） |

### ゲーム内無料取得ペース

| 手段 | 獲得コイン/日（目安） |
|-----|-----------------|
| ラン 3km | 300 コイン |
| デイリーミッション 3件 | 60〜900 コイン |
| 実績 | 単発（100〜5,000） |

→ 週 5km 走るユーザーは週に 500 コイン獲得 → 毎週 1 回ガチャを引ける設計

### アイテム設計

| 要素 | 仕様 |
|-----|-----|
| 全アイテム | 45種（コスメのみ） |
| ゲームプレイへの影響 | 完全にゼロ |
| 重複 | 取得済みフラグを ON（追加補填なし） |
| 天井（ピティ） | 現行なし（将来実装を推奨） |

---

## 2. 報酬広告（サブ収益源）

### 概要

広告を視聴することで、ガチャ 1 回分（500コイン）を無料取得できる。

### 実装詳細

| 項目 | 値 |
|-----|---|
| 広告タイプ | Rewarded Ad（Google Mobile Ads） |
| 報酬 | 500 コイン（= 1連ガチャ相当） |
| 上限回数 | 現行: 無制限（将来: 1日 N 回制限を推奨） |
| テスト ID (Android) | `ca-app-pub-3940256099942544/5224354917` |
| テスト ID (iOS) | `ca-app-pub-3940256099942544/1712485313` |

> **重要:** リリース前に本番広告ユニット ID へ差し替えること。

## リテンションフック（マネタイズ支援）

| 施策 | 説明 |
|-----|-----|
| デイリーミッション | 毎日コインを稼ぐ理由を提供 |
| ストリーク | 連続ログインへの心理的コスト |
| 週間目標 | 週次のゴールで帰還動機 |
| 実績 | 長期的なコイン獲得のマイルストーン |
| 進化ツリー | 18 ヶ月以上のプレイ期間を見通せる目標 |

---

## アンチホエール設計

| ガード | 仕様 |
|-------|-----|
| 課金でレベル購入不可 | レベルは走行距離に比例 |
| 課金でステータス強化不可 | 全アイテムがコスメのみ |
| 無料プレイヤーも最終コンテンツ到達可能 | 走れば全形態に到達 |
| 広告でガチャへのアクセスを担保 | 課金しなくてもガチャが引ける |
