# 11 ビジネス戦略

## エグゼクティブサマリー

Running Monster は「走ることを習慣化させるフィットネス × モンスター育成アプリ」として、健康アプリ市場とモバイルゲーム市場の交差点を狙う。コア差別化は「走った距離が直接ゲームの進歩に反映される」公平性と、長期的な育成システムによる高い継続率にある。

### ターゲットセグメント

| セグメント | 特徴 | 取り込み戦略 |
|---------|-----|----------|
| ランニング初心者（20〜35歳） | 継続できない。モチベーション不足 | ゲームループで習慣化支援 |
| 育成ゲームユーザー | 運動習慣はないがゲーム課金に慣れている | ランニングのゲーム化で取り込み |
| フィットネス中級者 | Strava 等を使うが飽きてきた | キャラクター育成の新鮮さ |

## 競合分析

| 競合 | 強み | 弱み | 差別化ポイント |
|-----|-----|-----|-----------|
| Strava | コミュニティ、詳細データ | ゲーム性なし、ビギナーに難しい | ゲームループ + 育成 |
| Nike Run Club | ブランド力、コーチング | 課金なし、進化なし | モンスター育成、ガチャ |
| ポケモン GO | 巨大 IP、GPS ゲーム | 歩行メイン、走る必要なし | 走ることに特化 |
| Finch | 育成愛着、メンタルヘルス | 運動連動が弱い | GPS 計測との直接連動 |
| Zombies, Run! | ストーリー、没入感 | 音楽必要、継続コスト高 | カジュアル、言語不問 |

## 収益化戦略

### フェーズ1（MVP）: 広告収益

- 報酬広告（Rewarded Ads）のみ
- ユーザーへの強制感なし
- 目標: 広告 ARPU ¥50/月

### フェーズ2（成長）: IAP 追加

- コイン IAP パッケージ導入
- 課金転換率 5% 目標
- 目標: ARPU ¥200/月

### フェーズ3（拡大）: イベント課金

- 期間限定ガチャ（限定モンスタースキン）
- バトルパス形式（週次課題＋報酬）
- 目標: ARPU ¥400/月

## リスク分析

| リスク | 深刻度 | 対応策 |
|-------|-------|-------|
| GPS 精度問題 | 中 | バリデーション強化・フォールバック |
| モンスターアート遅延 | 高 | 絵文字代替を β リリースまで許容 |
| チーター対策なし | 中 | サーバー検証なし（将来課題） |
| 競合の模倣 | 低〜中 | コミュニティ・キャラクター IP で堀を構築 |
| ストア審査拒否 | 低 | 広告・課金の規約準拠を事前確認 |
