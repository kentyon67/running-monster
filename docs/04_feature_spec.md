## F-01 GPS ラン計測

### 権限
- `LocationPermission.whileInUse` または `always` が必要
- 位置情報サービスが OS レベルで有効であること
- カメラ権限（QR スキャン用、ラン機能とは独立）

### フォアグラウンドサービス
- Android: ネイティブチャンネル `com.kentyon67.running_monster/foreground`
- `wakelock_plus` で CPU スリープを防止（ラン中は常時計測）

### 計測フロー
1. 「走る開始」タップ → 権限チェック → 位置情報サービス確認
2. GPS ポーリング開始（geolocator）
3. ルートポイント蓄積（RoutePoint[]）
4. リアルタイム距離計算（ハーバーサイン式）
5. ペース計算（分/km）
6. 一時停止中は距離・ルートを保持、GPS は停止
7. 完了 → バリデーション → RunRecord 保存

### バリデーション
```
isValid = distanceKm >= 0.5 && durationSeconds >= 180
異常速度（>25km/h の区間）は除外して再計算
```

## F-02 EXP・コイン報酬計算

```dart
// EXP 計算（疑似コード）
const double expCap = 1.8;  // 全ボーナス合算の上限

baseExp = distanceKm * 100
distanceMultiplier = distanceKm >= 10 ? 1.5 : distanceKm >= 5 ? 1.2 : 1.0
timeMultiplier = isMorning || isNight ? 1.1 : 1.0
// 将来ボーナスもここに乗算で追加
totalMultiplier = distanceMultiplier * timeMultiplier
finalExp = (baseExp * min(totalMultiplier, expCap)).round()

// コイン計算
coins = (distanceKm * 100).round()  // 乗数なし
```

**ボーナス乗数（掛け算方式・上限 1.8×）:**
- 距離: 10km 以上で 1.5×、5km 以上で 1.2×、それ以外 1.0×
- 朝ラン: **5:00〜7:59** で 1.1×
- 夜ラン: 20:00〜23:59 で 1.1×
- 全ボーナスを掛け合わせ、合算後に 1.8× でキャップ（現行最大: 1.65×）

## F-03 モンスター育成（レベルアップ）

### レベルアップ処理
1. `monster.exp += expGained`
2. `LevelCalculator.calculateLevel(monster.exp)` でレベル再計算
3. レベルが変化した場合:
   - `monster.level = newLevel`
   - `monster.isEvolutionAvailable` を進化条件チェック
   - `monster.skinUnlocked = true`（Lv50 到達時）
4. Hive に保存

### Lv50 ソフトキャップ
- EXP は引き続き加算するが `level` は 50 を超えない
- スキン解放フラグは Lv50 到達時に一度だけ設定

## F-04 進化システム

### 進化ツリー（全形態）

```
Lv 1: ランモン（カラー別 3 種：赤/青/緑）
        ↓ Lv10（2択）
Lv10: グランドモン ─── ウィングモン
        ↓ Lv20（2択）      ↓ Lv20（2択）
     ビーストモン ナイトモン  バードモン スピリモン
        ↓ Lv30（2択）  ↓     ↓         ↓
   フェンリルモン レオモン  パラディンモン ダークナイトモン
   フェニモン ライチョウモン ルクスモン ノクスモン
        ↓ Lv40（確定・選択なし）
   フェンリルロード / ソルレオンロード / セイントパラディン
   アビスナイトロード / フェニックスロード / サンダーバードロード
   ルミナスセラフ / ノクスファントム
```

**合計:** 1 + 2 + 4 + 8 + 8 = **23 形態** × 3 カラー = **69 パターン**

### 分岐点と選択ルール

| レベル | 分岐 | 選択 |
|-------|-----|-----|
| Lv10 | 2択 | ユーザーが選択 |
| Lv20 | 2択 | ユーザーが選択 |
| Lv30 | 2択 | ユーザーが選択 |
| Lv40 | 確定 | 自動（選択なし） |

### 進化ロジック
```
// Lv10/20/30 は 2択
条件: monster.level >= evolutionNode.requiredLevel
      && evolutionNode.requiredParent == monster.currentEvolutionId
→ isEvolutionAvailable = true（2択 UI 表示）
選択後: evolutionPath.add(chosenId), currentEvolutionId = chosenId

// Lv40 は確定進化
条件: monster.level >= 40 && currentEvolution は Lv30 形態
→ 唯一の最終形態へ自動進化（確認ダイアログのみ）
```

- Lv10/20/30 の選択は**不可逆**（通常プレイ）
- **リセット機能**でレベル・EXP・進化ルートを初期化可能
- 進化は見た目のみ、ステータスへの影響なし

```dart

roll = Random().nextDouble()
if roll < 0.02 → SSR
```

## F-16 モンスター感情システム

### 概要

モンスターはユーザーのランニング行動に連動して感情を変化させる。「走ったらモンスターが喜ぶ」という情動的なフィードバックが、アプリへの愛着とリテンションを支える最重要機能。

### 感情ステート定義

| ステート ID | 状態名 | 表情/ポーズ | トリガー条件 |
|-----------|-------|----------|-----------|
| `happy` | 嬉しい | 満面の笑み・体が弾む | ラン直後 |
| `excited` | 大興奮 | ジャンプ・目がキラキラ | レベルアップ直後 |
| `evolving` | 進化中 | 専用演出（後述） | 進化選択確定時 |
| `normal` | 普通 | 穏やか・呼吸アニメ | 通常（ラン後 30 分以降） |
| `lonely` | 少し寂しい | 目が少し下がる・ゆっくり揺れ | 最終ランから 3 日経過 |
| `very_lonely` | かなり寂しい | しおれた姿勢・うつむき | 最終ランから 7 日以上経過 |

### トリガーと遷移ルール

```
ラン完了保存          → happy（30分間継続）→ normal に戻る
レベルアップ          → excited（画面アニメ後 5秒）→ happy → normal
進化選択確定          → evolving（演出終了後）→ happy → normal
最終ランから 3日未満  → normal
最終ランから 3日以上  → lonely
最終ランから 7日以上  → very_lonely
ラン完了（lonely中）  → happy（復帰時に特別コメント）
```

### 各ステートの演出仕様

#### `happy`（ラン後）
- モンスターが小さくジャンプ（Scale 1.0→1.15→1.0、200ms × 3回）
- 目が弧を描く笑顔形状に変化
- ラン結果画面で発動 → ホーム画面でも 30 分間維持

#### `excited`（レベルアップ）
- 大きくジャンプ（Scale 1.0→1.3→0.95→1.05→1.0、elasticOut 700ms）
- 周囲に小さな星パーティクルが散る
- 効果音連動（将来実装）

#### `lonely`（3日未ラン）
- 呼吸アニメが通常より遅くなる（4秒サイクル）
- 表情が少し曇る（目が細くなる）
- ホーム画面に「〇〇ちゃんが待ってるよ」テキスト（薄く）

#### `very_lonely`（7日以上未ラン）
- ゆっくりとした縦揺れ（うつむき）
- 表情がかなり暗い
- ホーム画面に「最近会えてないね…走りに行こう」テキスト
- プッシュ通知でリエンゲージメント（通知設定 ON の場合）

#### `evolving`（進化演出）— 詳細は docs/08 参照

**Lv10/20/30 進化（分岐選択後）:**
1. モンスターが輝き始める（白いオーラが広がる）
2. シルエットに変化（フェードアウト）
3. 新フォームが光とともに登場（フェードイン）
4. 新フォームがジャンプ → `happy` 状態へ
- 演出時間: 約 3 秒

**Lv40 最終進化（確定進化）:**
1. 画面が一瞬白くフラッシュ
2. 「最終進化！」テキストがフェードイン
3. 壮大な光の演出（パーティクル + オーラ拡大）
4. 最終形態が堂々と登場
5. 専用ポーズ（台座に立つ・翼を広げる等、形態による）
- 演出時間: 約 5 秒

### コメント・テキスト仕様

| タイミング | テキスト例 |
|----------|---------|
| ラン完了直後 | 「やったー！一緒に走れて嬉しいよ！」 |
| 3日未ラン（ホーム） | 「…{name}、久しぶりだね。待ってたよ」 |
| 7日以上未ラン（ホーム） | 「走りに行こうよ…一緒に行こう」 |
| 7日以上後の復帰 | 「会えた！やっと会えた！もう離れないで！」 |
| レベルアップ | 「もっと強くなれた！ありがとう！」 |
| 進化直後 | 「これが新しい私… ありがとう、一緒に走ろう！」 |

- テキストはモンスター種族・カラーによらず共通（将来: 進化路線別に変更検討）
- `{name}` はモンスター名で置換

### データ管理

- `lastRunDate` から放置日数を計算してステート決定
- ステートは保存不要（起動時に毎回計算）
- `happy`/`excited` の残り時間は `lastRunDate` + 閾値で計算

## F-15 リセット機能

### 概要

モンスターの育成をやり直せる機能。別ルートの進化を試したいユーザー向け。

### リセット対象（初期化）

| データ | リセット後 |
|-------|---------|
| レベル | 1 に戻る |
| EXP | 0 に戻る |
| 進化ルート | ランモンに戻る |
| isEvolutionAvailable | false |

### 保持するデータ

| データ | 理由 |
|-------|-----|
| コイン | リセットのペナルティを与えない |
| ガチャ所持アイテム | 課金価値のあるデータは保護 |
| ラン履歴（RunRecord） | 運動記録はユーザーの資産 |
| 累計走行距離 | 実績・レベルの再計算基準になる |
| 実績達成状況 | 再達成は不要 |

### UX フロー

1. 設定画面「モンスターをリセット」タップ
2. 警告ダイアログ（リセット対象の明示）
3. 2段階確認（「本当にリセットしますか？」）
4. リセット実行 → ホーム画面へ
5. オンボーディングは表示しない（カラーも引き継ぐ）
