## F-01 GPS ラン計測

### 権限
- `LocationPermission.whileInUse` または `always` が必要
- 位置情報サービスが OS レベルで有効であること
- カメラ権限（QR スキャン用、ラン機能とは独立）

### フォアグラウンドサービス
- Android: ネイティブチャンネル `com.kentyon67.running_monster/foreground`
- `wakelock_plus` で CPU スリープを防止（ラン中は常時計測）

### 計測フロー
1. 「走る開始」タップ → 権限チェック → 位置情報サービス確認
2. GPS ポーリング開始（geolocator）
3. ルートポイント蓄積（RoutePoint[]）
4. リアルタイム距離計算（ハーバーサイン式）
5. ペース計算（分/km）
6. 一時停止中は距離・ルートを保持、GPS は停止
7. 完了 → バリデーション → RunRecord 保存

### バリデーション
```
isValid = distanceKm >= 0.5 && durationSeconds >= 180
異常速度（>25km/h の区間）は除外して再計算
```

## F-02 EXP・コイン報酬計算

```dart
// EXP 計算（疑似コード）
baseExp = distanceKm * 100
distanceMultiplier = distanceKm >= 10 ? 1.5 : distanceKm >= 5 ? 1.2 : 1.0
timeMultiplier = isMorning || isNight ? 1.1 : 1.0
finalExp = (baseExp * distanceMultiplier * timeMultiplier).round()

// コイン計算
coins = (distanceKm * 100).round()  // 乗数なし
```

**ボーナス乗数の優先順位（距離・時間帯は独立判定）:**
- 距離: 10km 以上で 1.5×、5km 以上で 1.2×、それ以外 1.0×
- 時間帯: 5:00〜7:59 または 20:00〜23:59 で 1.1×

## F-03 モンスター育成（レベルアップ）

### レベルアップ処理
1. `monster.exp += expGained`
2. `LevelCalculator.calculateLevel(monster.exp)` でレベル再計算
3. レベルが変化した場合:
   - `monster.level = newLevel`
   - `monster.isEvolutionAvailable` を進化条件チェック
   - `monster.skinUnlocked = true`（Lv50 到達時）
4. Hive に保存

### Lv50 ソフトキャップ
- EXP は引き続き加算するが `level` は 50 を超えない
- スキン解放フラグは Lv50 到達時に一度だけ設定

## F-04 進化システム

### 進化ツリー（全形態）

```
Lv 1: Runmon（カラー別 3 種）
       ↓ Lv10
Lv10: Beastmon ─── Spiritmon
       ↓ Lv20        ↓ Lv20
     Lionmon  Wolfmon  Phoenixmon  Dragonmon
       ↓ Lv30   ↓ Lv30    ↓ Lv30       ↓ Lv30
   Leomon Kingmon  Fenrirmon Arcticmon  Blazemon Shadowmon  Stormmon Crystalmon
```

**計 16 terminal 形態 × 3 カラー = 48 ユニーク外観**（実装上は同絵文字）

### 進化ロジック
```
条件: monster.level >= evolutionNode.requiredLevel
      && evolutionNode.requiredParent == monster.currentEvolutionId
結果: isEvolutionAvailable = true → UI で選択肢表示
選択後: evolutionPath.add(chosenId), currentEvolutionId = chosenId
       isEvolutionAvailable = false
```

- 選択は**永続・不可逆**
- 進化は見た目のみ、ステータスへの影響なし

## F-05 ガチャシステム

### 排出率

| レアリティ | 確率 |
|---------|-----|
| SSR | 2% |
| SR | 8% |
| R | 30% |
| N | 60% |

### コスト

| モード | コイン | 備考 |
|-------|-------|-----|
| 1連 | 300 | — |
| 10連 | 2,500 | 1連 × 10 より 500 コイン安 |
| 広告 | 0 | 報酬広告視聴で 1連分コイン獲得 |

### ガチャエンジン
```dart
// GachaEngine.pull() 疑似コード
roll = Random().nextDouble()
if roll < 0.02 → SSR
elif roll < 0.10 → SR
elif roll < 0.40 → R
else → N

// プール内からランダム1件を選択（既所持でも重複あり）
```

- **天井（ピティ）システム:** 未実装（純粋乱数）
- 重複アイテムは取得済みフラグが ON になるのみ（追加報酬なし）

## F-09 QR フレンド機能

### フロー
1. /profile でプロフィールカード表示 → QR 生成（qr_flutter）
2. データ内容: FriendCard の全フィールドを JSON エンコード
3. 相手が /friends でスキャン（mobile_scanner）
4. FriendCard をローカル保存 → フレンド一覧に追加
5. フレンドのステータスを閲覧可能（更新はリスキャンが必要）

## F-12 通知

- `flutter_local_notifications` + timezone
- トリガー:
  - ラン後のリマインダー
  - デイリーミッション通知
- ユーザーが設定画面で ON/OFF 切替可能
- 初回は Android/iOS の権限ダイアログが表示

## F-13 オンボーディング

- 初回起動時のみ（`onboarding_complete` フラグ）
- フロー: カラー選択 → 名前入力 → 説明 → 完了
- 完了後はスキップできない（/home へリダイレクト）
