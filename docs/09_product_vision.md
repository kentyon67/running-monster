# 09 プロダクトビジョン

## ミッション

> **「走ることを、誰かと生きることにする」**

Running Monster は、孤独になりがちなランニングという行為に「育てる喜び」と「つながる楽しさ」を加え、運動習慣を長続きさせるためのアプリです。

---

## コアバリュー

| バリュー | 説明 |
|--------|-----|
| **Run First** | 走ることが最高の体験。ゲームは走る理由であり、走りの邪魔をしない |
| **Honest Progression** | レベルはお金ではなく、汗の量で決まる |
| **Delightful, Not Addictive** | 毎日開けたくなるが、強制しない。習慣を支援する設計 |
| **Cosmetics Only** | 見た目だけが課金対象。ゲームプレイの公平性を守る |

---

## ターゲットユーザー

### メインターゲット
- **年代:** 20〜35歳
- **属性:** 運動習慣をつけたいが継続できない人
- **行動:** 走り始めたが 3ヶ月以内にやめてしまう経験がある
- **動機:** 健康維持よりも「達成感」「ゲーム感覚」「友人との話題」

### サブターゲット
- すでに走っている人（記録アプリ代わり ＋ キャラクター育成）
- ガチャ・育成ゲームが好きでフィットネスに興味がある人

---

## ポジショニング

```
                    ゲーム性（高）
                         |
           Running Monster ←ここ
                         |
運動主体（高） ────────────┼──────────── ゲーム主体（高）
   （Strava等）          |          （ポケモン GO）
                         |
                    ゲーム性（低）
```

- **Strava/Nike Run Club より:** ゲーム性があり、継続動機が強い
- **ポケモン GO より:** 走ることに特化、ゲームがランの邪魔をしない
- **Finch より:** コミュニティ（QR フレンド）と長期進化ツリーがある

## 競合・代替との差別化

| アプリ | 差別化ポイント |
|-------|------------|
| Strava | ゲーム性・キャラ育成がない。ビギナーには敷居が高い |
| ポケモン GO | 歩行/GPS ゲームだが「走る」に特化していない |
| Finch | 育成はあるが運動と直接連動していない |
| あすけん | 食事記録メイン。走る行動変容には弱い |

---

## 絶対に妥協しない原則

1. **走行距離がそのままレベルに反映される** — 課金バイパスなし
2. **広告はリワード型のみ** — インタースティシャルや強制広告は入れない
3. **ゲームが走りの妨げにならない** — 計測中 UI はシンプル最優先
4. **プライバシーファースト** — GPS データはローカル保存のみ（外部送信なし）

## 将来的な拡張ビジョン（参考）

以下はプロダクトビジョンの参考であり、現フェーズでは未実装・未確約。

- **ランキング機能** — 友人間の走行距離ランキング
- **モンスター対戦** — 育てたモンスターで友人と対戦（ターン制）
- **イベント走** — 期間限定モンスター・コスメ
- **Apple Watch / Wear OS 連携** — スマートウォッチからラン開始
- **クラウド同期** — 端末移行・バックアップ対応
- **コミュニティ機能** — ラングループ・チャレンジ
