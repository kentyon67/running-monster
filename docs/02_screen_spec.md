# 02 画面仕様

## ナビゲーション構造

### ボトムナビゲーション（5タブ）

| タブ | アイコン | ルート | 説明 |
|-----|---------|-------|-----|
| ホーム | directions_run | /home | ダッシュボード |
| ラン | play_arrow | /run | GPS 計測準備 |
| モンスター | pets | /monster | モンスター詳細 |
| ガチャ | auto_awesome | /gacha | ガチャマシン |
| 設定 | settings | /settings | アカウント・通知 |

### モーダル/フルスクリーン（push 遷移）

| ルート | 説明 |
|-------|-----|
| /run/active | ラン計測中（ボトムナビ非表示） |
| /run/result | ラン結果画面 |
| /missions | ミッション（デイリー・実績） |
| /profile | プロフィールカード（QR生成） |
| /friends | フレンド（QR スキャン） |
| /settings/privacy | プライバシーポリシー |
| /onboarding | 初回オンボーディング（条件リダイレクト） |

## ホーム画面 `/home`

### ヘッダー
- **AppBar タイトル:** 「ランニングモンスター」
- **右端チップ:** コインアイコン（金色）＋保有コイン数

### モンスターヒーローゾーン
- ラベンダーグラデーション背景（画面幅いっぱい）
- 時間帯別あいさつ文
  - 5:00〜10:59 → 「おはようございます」
  - 11:00〜16:59 → 「こんにちは」
  - 17:00〜20:59 → 「こんばんは」
  - 21:00〜4:59 → 「おつかれさまです」
- モンスター表示（画面幅 72%）＋ソフトカラー円形背景
- ユーザー名表示

### 進化バナー（条件付き表示）
- 進化可能時のみ表示
- シマーアニメーション付きバナー
- タップで /monster の Evolution タブへ遷移

### EXP バーカード
- 現在レベル・次レベルまでの進捗
- プログレスバー（アニメーションカウンター付き）
- 累積 EXP 数値

### ステータスチップ行（3列）

| 列 | 表示内容 | 単位 |
|----|--------|-----|
| 左 | 今日の走行距離 | km |
| 中 | 総走行距離 | km |
| 右 | 所持コイン | G |

### 週間目標カード
- 左: ストリークバッジ（炎アイコン＋日数＋「日連続」）
- 右: 週間目標プログレスバー（x.x / 30.0 km）
- 達成時: 「目標達成！」緑ラベル

### デイリーミッションカード
- 本日達成済み / 全ミッション数の比率
- プログレスバー
- ミッション画面へのリンクテキスト

### 走るボタン
- 大型 CTA ボタン（グロウエフェクト付き）
- テキスト: 「走る」
- /run へ遷移

## ラン準備画面 `/run`

### 背景
- **ライトテーマ背景**（ラベンダーホワイト系、星フィールド廃止）
- 時間帯に応じた暖色/涼色グラデーション（朝: オレンジ寄り、夜: 青紫寄り）
- Duolingo / Finch スタイル: 明るく・余白多め・モンスター主役

### コンテンツ
- **モンスター大表示（画面中心）**: 現在の感情ステートを反映（例: happy なら笑顔）
- モチベーションテキスト（時間帯別）
- ボーナスヒント（朝ラン 5:00〜7:59・夜ラン 20:00〜23:59・距離ボーナスの説明）
- 報酬広告ボタン（「広告を見てコインを貯める」）
- 「走る開始」ボタン（大型 CTA）
- 「続きから」ボタン（前回中断がある場合のみ）

---

## ラン計測中画面 `/run/active`

### リアルタイム表示
| 要素 | 仕様 |
|-----|-----|
| 走行距離 | x.xx km |
| ペース | x:xx /km |
| 経過時間 | HH:MM:SS |
| GPS ステータス | 精度インジケーター |

### マップ
- flutter_map（OpenStreetMap）
- リアルタイム赤ポリライン（ルート描画）
- 現在地マーカー

### コントロール
- 一時停止 / 再開ボタン
- 完了ボタン（長押し or 確認ダイアログ）

---

## ラン結果画面 `/run/result`

### 表示内容
- 走行距離、ペース、タイム
- 獲得 EXP（アニメーションカウンター: 0→n）
- 獲得コイン（アニメーションカウンター: 0→n）
- 適用ボーナスラベル（「朝ランボーナス！」等）
- ルートマップ（プレイバック）

### 条件付き演出
- レベルアップ: 弾性バウンスアニメーション＋レベルテキスト
- 進化解放: バナー表示

### アクション
- 保存ボタン → リポジトリに保存してホームへ
- バリデーションエラー時: エラーメッセージ表示（保存なし）

---

## モンスター画面 `/monster`

### Tab 1: ステータス
- モンスター名・現在レベル・進化形態
- モンスターアートワーク（大）
- EXP プログレスバー
- 進化履歴の表示

### Tab 2: 進化
- 現在の進化位置（ツリー内）
- 次の進化選択肢（最大 2 分岐）
- 各選択肢のプレビュー（名前・絵文字・説明）
- 「選択」ボタン（進化可能時のみ活性）

### Tab 3: アイテム
- 所有コスメアイテム一覧（スキン・オーラ・バナー・フレーム）
- レアリティカラー表示
- 「装備」ボタン（装備中は「装備中」表示）

---

## ガチャ画面 `/gacha`

### ガチャマシンウィジェット
- マシンアニメーション（1200ms サイクル）
- コイン残高表示

### ボタン
| ボタン | コスト | テキスト |
|-------|-------|--------|
| シングル | 500 コイン | 「1回引く」 |
| 10連 | 4,500 コイン | 「10連」 |
| 広告 | 無料（広告視聴） | 「無料で引く」 |

### 結果モーダル
- レアリティ別背景色
  - SSR: ゴールド
  - SR: マゼンタ
  - R: スカイブルー
  - N: グレー
- アイテム名・説明・レアリティ表示

---

## ミッション画面 `/missions`

### Tab 1: デイリーミッション
- 本日の 3 ミッション一覧
- 各ミッション: タイトル・条件・報酬コイン・達成チェック

### Tab 2: 実績
- カテゴリ別（距離・レベル・ガチャ・ストリーク）
- 各実績: タイトル・条件・進捗・報酬・達成日

---

## 設定画面 `/settings`

| 項目 | 仕様 |
|-----|-----|
| ユーザー名変更 | 自由に何度でも変更可能 |
| モンスター名変更 | 初回設定後に **1回のみ** 変更可能（残り回数表示） |
| 通知切り替え | ON/OFF トグル |
| プロフィールカード | /profile へ遷移 |
| フレンド | /friends へ遷移 |
| プライバシーポリシー | /settings/privacy へ遷移 |
| 装備中コスメ表示 | タイトル・バナー・フレーム |

---

## プロフィールカード画面 `/profile`

- プロフィールカード UI（バナー・フレーム・アバター・称号）
- QR コード生成（JSON エンコード）
- シェアボタン（share_plus / gal で画像保存）

---

## フレンド画面 `/friends`

- QR スキャン（mobile_scanner）
- 取り込み済みフレンドカード一覧
- フレンドのステータス閲覧（読み取り専用）

---

## オンボーディング `/onboarding`

- 初回起動時のみ表示（完了フラグで制御）
- **カラー選択（赤・青・緑）:** モンスター種族は「ランモン」1種のみ。色だけを選ぶ
- **モンスター名入力:** 初期名を設定（後から1回だけ変更可）
- **ユーザー名入力:** 表示名（後からいつでも変更可）
- チュートリアル説明
- 完了後 /home へ遷移
