## コンポーネントパターン

### ボタン

**プライマリボタン:**
- 形状: Pill（border-radius: 100）
- 背景: `#7C4DFF`
- テキスト: White、16px、Bold、letter-spacing: 0.5
- Elevation: 4
- パディング: 横 32px・縦 16px（推奨）

**グロウボタン（CTA）:**
- プライマリボタン ＋ BoxShadow（`#9C6FFF`, blur 16px, spread 0）
- 「走る」ボタン等の主要アクションに使用

**無効状態:**
- 背景: ライトボーダー色
- テキスト: ミュートテキスト色
- Elevation: 0

## レスポンシブ考慮

- **基準デバイス:** 375px 幅（iPhone SE 相当）
- **モンスター表示幅:** 画面幅 × 0.72
- **フォントスケーリング:** TextScaler.noScaling 推奨（アクセシビリティとの要検討事項）
- **横向き:** 非推奨（縦固定を前提とした UI 設計）
